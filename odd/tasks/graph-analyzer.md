- S3 Canvas: "Clic para crear nodos (vértices)". "Selección de dos nodos para trazar aristas (segmentos)". "Dirigidas (flechas)", "Bucles (mismo nodo)", "Ponderadas (asignar peso W(s) no negativo)". Drag & drop nodes. "Herramienta para seleccionar un subconjunto de nodos M y aristas T, y que el sistema los aísle visualmente como un \"Subgrafo\" H del grafo original G".
- S4 Classification (real time): "Multigrafo: Detección de múltiples aristas entre los mismos nodos o bucles". "Digrafo: Detección de aristas dirigidas". "\"Conexo\" (hay trayectoria entre cualquier par de nodos) o \"No conexo\"". "\"Grafo Completo\" (Kn)", "\"Grafo Plano\" (sin cruces de aristas)", "\"nCubo\" (Qn) donde los vértices representan cadenas de bits".
- S5 Metrics: "Matriz de Adyacencia: Generar matriz booleana n x n, soportando grafos asimétricos (dirigidos) y sumando +1 por cada arista múltiple en multigrafos". "Calcular g(v) (separando gri y gro si es dirigido) y validar en pantalla que Σ gr(v) = 2|s|". "Identificar Nodos Aislados, Fuentes (gri=0) y Sumideros (gro=0)". "Si es plano y conexo, mostrar cálculo de Regiones: N - S + R = 2". "En digrafos, un bucle cuenta como 1 salida y 1 entrada simultáneamente".
- S6 Routes: select u and v; "Distancia d(u,v): La longitud de la trayectoria más corta entre u y v". "Camino Mínimo (Ponderado): Si hay pesos, encontrar el camino con el peso mínimo absoluto". Illuminate the shortest path ("BFS para no ponderados, Dijkstra para ponderados"). Route traced by the user: "Sendero" (todas las aristas son diferentes), "Trayectoria" (todos los nodos son diferentes), "Circuito" (camino cerrado), "Ciclo" (camino cerrado con vértices diferentes excepto 1º y último). "distingue perfectamente entre un Sendero (permite repetir nodos pero no aristas) y una Trayectoria (no permite repetir nodos)".
- S7: "Toda la matemática de grafos (matrices, Dijkstra/BFS para caminos) debe encapsularse en una clase 'GraphEngine'". "El DOM/Canvas no debe hacer cálculos."
- S8: "La Matriz de Adyacencia se renderiza correctamente reflejando aristas múltiples en la celda correspondiente (ej: valor 2 si hay dos aristas paralelas)". "Permite auto-generar desde un botón un grafo \"Q2\" o \"Q3\" (nCubo) para pruebas rápidas."
- Assumptions (stated to user): the referenced academic document ("[cite: N]") was not supplied; definitions follow the prompt text. "Plano" is evaluated on the current drawing (crossings); when crossings exist, necessary planarity bounds are reported instead of a false verdict. Mixed graphs: an undirected edge counts as two-way for reachability and sources/sinks; connectivity is weak connectivity (strong reported separately for digraphs). An undirected loop adds 2 to g(v) and 1 to the matrix diagonal. Unweighted edges weigh 1 for Dijkstra.
- S9 (supersedes S3 canvas tools, S6 route tracing, S8 Q2/Q3 buttons): "mucho mas simple la seccion de grafo la veo complicada es mas para estudiar pone de generar un grafo aleatorio y que te de sus caracteristicas arbol, etc marcar caminos de formas sencillas etc". Manual drawing, weights, directed edges, subgraph and route tools removed from the UI. Nodes can still be dragged.

- S11 (amends S9/S10): user pasted the Bipartito, Regular, Plano and Euleriano feature items with "saca esto" — remove those four from the characteristics list. "y lo del camino pone marcar camino": the Euler trail toggle is labelled "Marcar camino" / "Ocultar camino" (interpretation stated to user).
